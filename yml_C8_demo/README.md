# yml_C8_demo · 企业本体 Agent 系统（早期验证物）

方向 B（企业本体 Agent 系统）的可运行早期验证物：一套**零第三方依赖**的本体 + 属性图 + Agent 工作流骨架，落地场景为电信运营商数字孪生。

## 运行

```bash
python demo.py        # 端到端演示
python test_demo.py   # 自检断言
```

仅依赖 Python 标准库（json/内置类型），任何机器可直接复跑，延续 C9「纯标准库」原则。

## 结构

| 文件 | 职责 |
|---|---|
| `ontology.py` | T-box（类层级/对象属性/数据属性）+ A-box（实例/断言）+ 一致性校验 |
| `graph.py` | 属性图（节点+边），schema 强约束（label/关系必须命中本体） |
| `agent.py` | 本体引导 Agent 工作流：意图解析 → 本体消歧 → 图遍历 → 答案 |
| `demo.py` | 端到端演示入口 |
| `test_demo.py` | 自检断言 |

## 设计要点

- **本体消歧**：同一提及词命中多个候选时，用本体类型层级（如「基站 ⊂ 站点 ⊂ 网络资源」）过滤，只保留 domain 合规的实体——demo 第 [4] 节用「B」证明纯关键词会把「客户 B2C客户组」也当答案，本体则精确锁定「基站B」。
- **确定性推理**：意图解析与答案生成两端留给 LLM（本机 ollama 可选，规则引擎兜底可跑通），中间实体消歧与图遍历由本体 + 图保证，可审计、可回放，不把正确性押在模型幻觉上。
- **schema 强约束**：图上节点/关系未在本体注册会直接报错，从源头杜绝「图上出现本体未定义概念」这一企业知识库常见烂尾。
